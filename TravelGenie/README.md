# TravelGenie - SIH 2026 Prototype

## Overview
TravelGenie is an AI-powered personalized travel planner.

## Setup Instructions
1. Navigate to the project root.
2. Run `npm install` to install dependencies.
3. Copy `.env.example` to `.env` and configure any available API keys.
4. Run `npm start` to start the backend server.
5. Open `index.html` in your web browser.

## Features
1. Home
2. Plan My Trip
3. AI Recommendations
4. Destination Details
5. AI Itinerary
6. Budget & Trip Cost
7. AI Travel Assistant
